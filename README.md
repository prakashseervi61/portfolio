## Features

- Multi-page routing with per-project detail pages
- Scroll-triggered GSAP animations, smooth scrolling via Lenis
- Stacked hover previews on the project list
- Active-section tracking in the slide-out menu
- Keyboard-accessible menu (Escape to close, focus trap, scroll lock)
- Route-change scroll restoration
- `prefers-reduced-motion` support and fine-pointer-gated custom cursor
- GitHub Pages SPA fallback via `404.html`
- Fully responsive from 320px up

## Getting Started

```bash
git clone https://github.com/prakashseervi61/portfolio.git
cd portfolio
npm install
npm run dev
```

| Script | Description |
|--------|-------------|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build into `dist/` |
| `npm run lint` | ESLint |
| `npm run preview` | Preview the production build |

> The app is served under the `/portfolio/` base path (`vite.config.js` + `BrowserRouter basename`).
