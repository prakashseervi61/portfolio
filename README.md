## Features

- Animated preloader with name reveal
- Smooth scroll with Lenis
- GSAP scroll-triggered animations
- Custom cursor
- Interactive project showcase with hover previews
- Active section tracking in sidebar
- EmailJS contact form
- Fully responsive

## Getting Started

```bash
# Clone the repository
git clone https://github.com/prakashseervi61/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
